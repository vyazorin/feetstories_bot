\# FeetStories Bot



Telegram-бот и backend для интерактивных 18+ историй FeetStories.



\## Запуск локально



1\. Скопируйте `.env.example` в `.env`.

2\. Укажите `BOT\_TOKEN` и параметры базы данных.

3\. Выполните:



```bash

npm install

npm run dev

```



\## Деплой



Проект предназначен для деплоя на Bothost из ветки `main`.
